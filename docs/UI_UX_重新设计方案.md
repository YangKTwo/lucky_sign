# 今日幸运签 UI/UX 重新设计方案

## 设计结论

新界面的目标不是把“幸运”做得更花哨，而是让成员在一天中最短的一次打开里完成一个判断：**我今天要做什么，现在离完成还差多远。**

设计采用“夜间签册”方向：像在安静桌灯下打开一本每日行动记录，而不是国潮装饰、游戏任务面板或社交信息流。它将当前的暖白底、橙色主色与大圆角卡片，调整为清晰的深色行动底盘、温和的纸张内容层和语义明确的状态颜色。

## 1. 目标用户与任务

| 场景 | 用户状态 | 主任务 | 设计回应 |
| --- | --- | --- | --- |
| 早晨快速查看 | 时间少、想知道今天做什么 | 看任务与奖励 | 今日页首屏只保留任务状态、行动按钮与截止时间 |
| 晚间补打卡 | 有轻度紧迫感 | 快速上传凭证 | 固定主按钮，提交面板提供文字、相册、拍照三种清晰选择 |
| 浏览社区 | 想即时沟通 | 看未读、回复 @、聊天 | 未读与 @我分开表达，社区只承担实时聊天 |
| 浏览动态 | 想了解圈友近况或分享成果 | 看图文动态、发布、点赞评论、看榜单 | 使用朋友圈式单列时间线，本周榜作为紧凑模块嵌入顶部 |
| 管理圈子 | 目标明确、低频 | 审核、解锁、删除内容 | 管理动作收纳在“我的 > 圈子管理”，并保留清晰后果说明 |

## 2. 视觉方向

### 场景句

用户在一天开始前或结束后，坐在台灯旁用手机确认自己的小目标；屏幕应像一本被翻开的签册，沉静、有方向感，但不神秘也不幼态。

### 色彩策略

采用 **Committed** 策略：深墨绿承担约 35% 的今日页顶部与重要背景，瓷白承载阅读内容，朱红只用于完成任务和风险操作，松石蓝用于社区与信息状态。等级色是数据色，不参与大面积背景。

| Token | 色值 | 用途 |
| --- | --- | --- |
| `ink` | `#102B2A` | 深色顶区、主标题、夜间签册基底 |
| `surface` | `#FCFCF8` | 页面主体与表单背景，避免奶油色 |
| `surfaceRaised` | `#FFFFFF` | 内容承载面与底部导航 |
| `action` | `#C8422E` | 主操作、紧急倒计时、撤回确认 |
| `community` | `#117C82` | 社区未读、@我、链接与信息状态 |
| `reward` | `#D8A635` | 幸运星、积分奖励和高价值提示 |
| `line` | `#D8DEDA` | 轻边界、分隔线 |
| `muted` | `#536866` | 次要文字，确保在浅色背景上的可读性 |
| `danger` | `#B3261E` | 错误与管理员删除 |

### 字体与图标

1. Flutter 端保持系统无衬线：Android 使用 Roboto，iOS 使用 SF Pro，Web 使用系统字体回退；避免中文品牌字体造成字体包膨胀和小字号可读性下降。
2. 只在幸运签等级和日期上使用较强字重；页面标题 28/700、区块标题 18/700、正文 16/400、辅助文字 13/500、标签 12/600。
3. 使用 Material Symbols / 现有 Material Icons；图标只辅助识别，不使用表情符号作为核心层级。

### 标志性元素

“签章进度条”：在今日任务区域以一枚半填充的圆角方形签章表示完成状态，内部是当天难度字母或完成勾选。它连接幸运签的语义与行动进度，而不是作为无意义装饰。

## 3. 导航与页面架构

紧凑宽度（手机）保留 4 个顶级目的地；中等以上宽度转为 NavigationRail，避免平板仍套用手机底栏。

```text
今日                 社区                动态                我的
任务 / 打卡          未读 / @我          图文发布            资料 / 提醒
历史 / 称号          实时聊天            互动 / 本周榜         语言 / 安全 / 管理
```

## 4. 今日页重构

### 页面层级

```text
安全区
  顶部：周几、日期、通知/刷新
  深色“今日签”区
    难度签章 + 幸运星状态
    一句幸运提示
    距结算倒计时
  主任务区（白色内容层）
    今日任务正文
    奖励积分 / 连续天数
    [完成并分享] 固定主操作
  进度行：当前称号 -> 下一称号
  轻量统计：积分、连续、圈内名次
底部导航
```

### 状态设计

| 状态 | 显示 | 主操作 |
| --- | --- | --- |
| 未完成且时间充足 | 任务区清晰、倒计时为中性色 | `完成并分享` |
| 未完成且 18:00 后 | 倒计时转朱红，文案强调“今天仍可完成” | `现在完成` |
| 已完成 | 签章填充、任务卡显示凭证摘要 | `查看社区动态` |
| 休眠账号 | 用文字与锁图标说明原因，不只变灰 | `联系管理员` |
| 加载中 | 顶区使用固定尺寸的骨架屏 | 无 |
| 加载失败 | 保留页面框架，显示问题和图标按钮重试 | `重新加载` |

### 打卡面板

使用原生底部 Sheet：标题“完成今天的任务”，包含 3 行感受输入、两个 48dp 图标操作（相册、拍照）、图片预览和底部全宽提交按钮。提交期间按钮文字变为“正在提交”，不可重复点击；成功后 Sheet 关闭并以轻量成功反馈确认“已同步到社区”。

## 5. 社区页重构

### 信息结构

1. 顶部保留圈子名和成员数；右侧只保留搜索/成员入口，不堆叠功能。
2. 当存在 @我时，使用一条松石色紧凑提示条“2 条消息需要你回应”，点击跳转第一条 @；普通未读则显示中性数量。
3. 消息按日期分段；社区只保留即时聊天与系统提醒，不承载朋友圈式动态流。
4. 被撤回或管理员删除的消息维持高度与时间戳，采用低对比中性色，避免时间线跳动。
5. 输入栏固定底部：@ 按钮、可扩展输入框、发送图标按钮。不可发送时发送按钮禁用。

### 消息动作

长按消息进入原生 Bottom Sheet：复制、撤回（仅本人且 2 分钟内）、管理员删除（仅管理员）。破坏性操作必须二次确认；撤回说明“撤回后所有成员都会看到该消息已撤回”。

## 6. 动态、排行与个人页

### 动态

动态使用熟悉的朋友圈式单列结构，但不照搬微信视觉：头像和昵称形成左侧锚点，正文与图片在右侧内容列展开；点赞与评论使用紧凑操作条。顶部先显示一条“本周榜”模块，仅展示前三名和“我的名次”，点击进入完整排行。右上角发布按钮进入独立发布页，支持文字、相册、拍照和最多 9 张图片。

### 排行

排行榜不再作为一级导航。完整排行由动态页的“本周榜”模块进入，首屏先展示“我的位置”，后展示完整榜单。前三名使用等级/称号差异，而不是奖杯图标堆叠；积分变化通过小型趋势标记表达。

### 我的

页面以账户控制为主：个人资料、语言、打卡提醒、账号与密码、反馈。管理员额外出现“圈子管理”入口，里面承载审批和内容治理，避免普通用户看到没有权限的功能。

### 中英切换

登录页与四个一级页面右上角显示紧凑的 `中 / EN` 分段按钮；当前语言有实色选中态。切换后仅应用界面文案、日期、数字和系统反馈本地化，聊天、动态与打卡等用户生成内容保留原文。设置页提供相同选项和“跟随系统”开关，简体中文为默认回退语言。

## 7. 组件规格

| 组件 | 规格 |
| --- | --- |
| 页面边距 | 手机 20dp；内容最大宽度 680dp |
| 触控目标 | Android 至少 48dp，iOS 至少 44pt |
| 内容容器圆角 | 12dp；Sheet 顶部 20dp；标签才可使用全圆角 |
| 主按钮 | 52dp 高，全宽，`action` 背景；加载/禁用/错误状态完整 |
| 次按钮 | 40-44dp 高，描边或文字样式；不与主按钮竞争颜色 |
| 列表行 | 最小 64dp；分隔线替代重复卡片边框 |
| 动效 | 150-220ms；仅用于提交成功、未读出现、页面状态切换；Reduce Motion 下直接淡入/切换 |
| 焦点与无障碍 | 明确焦点环；所有色彩状态配图标/文字；动态字号下可换行且不遮挡 |

## 8. 交付与验收

1. 首屏 10 秒内可回答“今天任务是什么、还剩多久、怎么完成”。
2. 提交打卡不超过 3 个交互步骤，不必离开今日页。
3. 社区未读和 @我可一键跳转且不会将已删除消息误计为需处理。
4. 手机、平板、Web 三端均不出现底栏遮挡输入框或文本溢出。
5. 暗色主题应作为后续版本的一等主题；首期先保证浅色主体与深色今日区的对比度。
