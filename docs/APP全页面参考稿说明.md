# 今日幸运签 App 全页面参考稿说明

本套参考稿按国内用户默认简体中文设计，四个一级导航为“今日 / 社区 / 动态 / 我的”。每个一级页面右上角提供 `中 / EN` 语言切换按钮；用户生成内容不随界面语言翻译。

| 编号 | 页面 | 核心用途 |
| --- | --- | --- |
| 01 | 登录 | 邮箱密码登录、语言切换、进入注册 |
| 02 | 注册 | 昵称、邀请码、邮箱密码与审批说明 |
| 03 | 今日 | 今日签、倒计时、任务、奖励与完成操作 |
| 04 | 完成打卡 | 填写感受、拍照/相册、预览并同步社区/动态 |
| 05 | 社区 | 纯聊天、未读、@我、撤回和输入栏 |
| 06 | 动态 | 朋友圈式图文流、本周榜模块、点赞评论和发布入口 |
| 07 | 发布动态 | 文字、最多 9 图、可见范围和发布操作 |
| 08 | 动态详情 | 图文详情、点赞成员、评论列表和评论输入 |
| 09 | 完整排行 | 从动态页本周榜进入，显示我的位置和完整榜单 |
| 10 | 我的 | 资料、积分称号、提醒、语言、安全、反馈和管理入口 |
| 11 | 语言设置 | 简体中文、English、跟随系统与即时预览 |
| 12 | 圈子管理 | 注册审批、成员状态和内容治理 |

图片是布局、层级与视觉语言参考，不是像素级开发稿。图中文字最终必须由 Flutter 的真实本地化资源渲染，不应将图片中的文字作为素材嵌入应用。
